## ◈ About J.A.R.V.I.S.

**J.A.R.V.I.S.** is a browser-based AI personal assistant that combines multiple AI models, voice interaction, coding tools, research, document reading, memory and productivity features in one futuristic workspace.

Instead of switching between multiple applications, users can access several AI-powered tools from a single dashboard.

Built with HTML, CSS and JavaScript, and powered by OpenRouter, J.A.R.V.I.S. is designed to make AI more accessible, useful and organised.

## 🎯 WHY J.A.R.V.I.S.?

Most AI tools focus on one main purpose. J.A.R.V.I.S. explores how multiple AI technologies and productivity tools can work together.

Its main goals are:

- Make multiple AI models accessible from one place.
- Support voice-based AI interaction.
- Help students and developers with coding and learning.
- Make document reading and research easier.
- Organise tasks, notes and project information.
- Explore the future of personal AI assistants.
